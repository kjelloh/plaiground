# generated_bas

These files are derived from information provided for download at [GRATIS KONTOPLANER FÖR 2026](https://www.bas.se/kontoplaner/) and [TIDIGARE KONTOPLANER](https://www.bas.se/kontoplaner/tidigare-kontoplaner/).

**ALL rights to the original work remains with creator(s) of these works.**

* bas_to_name_yyyy.csv suggests a mapping from a BAS one,two,three or four digit number to a name.
* bas_to_meta_yyyy.csv suggests a mapping from BAS BAS one,two,three or four digit number to a meta property for account(s).

At no time shall information in these files be treated as officially proposed nor trusted at such.
